# DeepSeek 静态复刻站

线上访问：https://liziliangli73-max.github.io/deepseek-clone/

DeepSeek 首页与开放平台后台的静态复刻，包含响应式布局、图表交互与导出功能。

- `index.html` — 首页
- `platform.html` — 开放平台 · 用量信息（按 Magpie Gateway 实际 V4.1 Flash 用量折算）
- `apikeys.html` — 开放平台 · API keys
- `topup.html` — 开放平台 · 充值
- `billing.html` — 开放平台 · 账单

纯静态、零构建、离线可用。
